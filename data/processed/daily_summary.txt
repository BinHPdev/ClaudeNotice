本周 Anthropic 发布 Claude Fable 5.1 与 Mythos 5.1，官方 claude-api skill 也已把默认模型切换为 Opus 5.5，并新增 Sonnet 5.5 支持；Mistral Large 4 同期登陆 Hugging Face，模型层竞争持续升温。开源生态继续围绕 Claude Code 扩展，上下文压缩（context-mode）、成本控制（TokenEconomizer）、规格驱动开发（OpenSpec）以及各类 Skill 插件集中涌现，"Skill 化"已成为提效工具的主流形态。安全方面，dev.to 有文章称某次已签名的 Claude Code 自动更新被植入后门、波及约 5000 名开发者，供应链安全再度引发关注。Anthropic Research 同期发布费马大定理形式化研究，以及 AI 智能体如何影响专家判断的研究，AI 辅助推理与人机协作正走向更深层次。
